# BMW 325iX Maintenance Evidence Corpus

This release includes a derived read-only manual index built from the existing Drive maintenance lanes. It contains 37 extracted source documents and 1,414 page/section records.

Coverage includes:

- factory/TIS reference pages;
- 1988 325iX electrical/ETM reference pages;
- public OES/catalog extracts and ATE Classic catalog pages;
- community repair, steering, suspension, driveshaft, transfer-case and viscous-coupling evidence;
- RAGFlow evaluation and ingestion guidance.

Every record retains source URL, source class, evidence tier where available, variant scope, page/section hash, publisher and rights caveat. Public accessibility is not treated as BMW authorization, model-specific repair approval or reuse permission. Community material is research evidence only and must not be treated as a repair procedure without independent verification.

The bundled `maintenance_manual_index.sqlite3` is the app's default manual index. The raw downloaded files remain in the separate maintenance-corpus archive and are not rewritten by the Workbench.
